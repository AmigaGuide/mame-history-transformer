# Output Folder

This folder is used to store intermediate and final output files generated by the TM470 project.

### Typical Contents
- `gh_entries.json` — Parsed metadata from Gaming-History XML
- `mame_cleaned.json` — Filtered and structured output from MAME XML
- `lit_wiki_ready.json` — Final merged dataset ready for import into ExoticA’s *Lost in Translation* wiki

### Notes
- This folder is excluded from Git version control using `.gitignore`.
- This file (`README.md`) is intentionally committed to preserve folder structure and explain its purpose.
- All other contents are generated automatically and should not be tracked in version control.
