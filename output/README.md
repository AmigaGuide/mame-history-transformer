# Output Folder

This folder is used to store **intermediate and final output files** generated by the TM470 *Lost in Translation* project.

## Typical Contents

- `exotica_lit_wiki.json`  
  Wiki-ready JSON with a compact, site-facing schema (used to populate ExoticA’s *Lost in Translation* wiki infoboxes).

- `exotica_lit_raw_data.json`  
  Full review-facing dataset including all structured fields, useful for QA and potential future renderers.

- `exotica_wiki_pages_and_redirects.json`  
  Sorted page names, machine→page mappings, and case-insensitive redirect sources with conflict checks.

- `gh_ini_classifications.json`  
  Aggregated classifications derived from Gaming-History INI files (game status, category, type).

- `gh_system_ports.json`  
  Normalised `PORTS` entries from Gaming-History XML, keyed by system shortname.

- `mame_machines.json`  
  Canonical unfiltered dump of MAME machine metadata.

- `mame_parent_index.json`  
  Parent–clone relationships, stored as both parent→clones and clone→parent mappings.

## Notes

- This folder is excluded from Git version control using `.gitignore`.  
- This `README.md` is intentionally committed to preserve folder structure and explain its purpose.  
- All other contents are **generated automatically** by the pipeline and should not be tracked in version control.
